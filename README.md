## 실행
`index.html`을 열거나 폴더 전체를 GitHub 저장소에 업로드한 뒤 Pages를 활성화하세요.

## 교체할 항목
1. `assets/images/hero-01.svg`~`09.svg`: 히어로 사진 9장
2. `story-01.svg`~`10.svg`: 3번째 섹션 사진 10장
3. `reserve-01.svg`~`10.svg`: 6번째 섹션 사진 10장
4. `index.html`의 `VIDEO_ID`: 메인 유튜브 영상 ID
5. `SHORT_VIDEO_ID_1`, `SHORT_VIDEO_ID_2`: 객실 쇼츠 영상 ID
6. `https://booking.naver.com/`: 실제 네이버 예약 URL

동일한 파일명을 유지한 채 JPG/WEBP 파일로 교체할 경우 index.html의 확장자도 바꿔주세요.
